Reports a dynamic dispatch string that names a method which does not exist on the configured class.

When a PSA JavaScript method argument provider maps a call such as $el.advanceLender('updateTrancheReferrers', tranche) to a class, this inspection checks that the string method name actually exists among that class's prototype methods. If it does not (and the class itself resolves to at least one known method), the name is reported as unknown — catching typos in the dispatched method name.

This inspection is only active when your PSA script's Info response enables it via js_method_argument_inspections: true. When the flag is absent or false, the inspection does nothing. See the JavaScript extension documentation for details.
