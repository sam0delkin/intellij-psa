Reports arguments inside a dynamic method's arguments array whose type is not accepted by the resolved method parameter.

When a PSA method argument provider maps an arguments array to a real method (for example new ServiceMethodMessage([Manager::class, 'doWork'], [$account, 1])), this inspection checks each value against the corresponding parameter using PhpStorm's own type checker. In files with declare(strict_types=1) scalar coercions that PHP would reject at runtime (such as int → bool) are reported; otherwise only hard incompatibilities (such as passing a wrong class) are reported. The standard Cast… quick fixes are offered.

A mismatch is reported as an error when the target method's file declares strict_types, and as a warning otherwise.

Configure the providers via the method_argument_providers field of your PSA script's Info response. See the PHP extension documentation for details.
